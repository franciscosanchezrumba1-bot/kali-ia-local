# Seguridad y buenas prácticas

- Ejecuta solo sobre activos autorizados.
- Revisa cada confirmación antes de ejecutar comandos críticos.
- Mantén logs para auditoría.
- No expongas Open WebUI públicamente sin hardening/autenticación.
- Revisa los reportes JSON en `reports/` antes de reutilizar resultados.
- Metasploit, sqlmap, hashcat y john requieren autorización explícita del entorno objetivo.
